# SQL Lab

Интерактивная учебная PostgreSQL-платформа, которая целиком работает в браузере и публикуется как статический сайт на GitHub Pages.

## Возможности

- Настоящий PostgreSQL через PGlite/WebAssembly, без backend и SharedArrayBuffer.
- SQL-редактор с автодополнением схемы, историей и именованными запросами.
- Интерактивная ERD Crow's Foot одновременно с SQL на десктопе.
- Просмотр и редактирование данных, импорт CSV/JSON.
- Генератор валидных синтетических строк с учётом PK/FK и автосохранение черновиков.
- SQL слева и ERD справа по умолчанию; скрытие схемы/результата и смена панелей местами.
- Три пресета с описанием сущностей, десятью Markdown-заданиями и стартовыми запросами.
- Автопроверка решений по эталонному SQL и редактор собственных заданий с правилами приёма.
- Конструктор таблиц с типами PostgreSQL, PK/UNIQUE/NOT NULL, DEFAULT и одиночными/составными FK.
- Редактирование DDL, компактные ссылки на сценарии и полный `.sqllab.json` backup.
- Светлая и тёмная темы.

## Локальный запуск

```sh

```

```sh
pnpm lint

pnpm build
pnpm exec playwright install chromium firefox
pnpm test:e2e
```

## GitHub Pages

1. Создайте репозиторий и отправьте ветку `main`.
2. В **Settings → Pages** выберите источник **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` сам соберёт и опубликует `dist`.

`base` Vite вычисляется из `GITHUB_REPOSITORY`. Для локальной проверки project path можно использовать `VITE_BASE=/sql-lab/ pnpm build`.

## Ссылки и хранение

`/#/w/<id>` восстанавливает рабочее пространство только в том браузере и на том origin, где оно создано. Данные PGlite и метаданные находятся в IndexedDB, несохранённые черновики строк — в localStorage. Очистка сайт-data удалит их, поэтому для важной работы используйте экспорт.

«Поделиться» создаёт независимую копию сценария: схему, текущие данные, заметки и стартовые запросы. Для встроенных пресетов передаётся patch к конкретной версии. Большие сценарии и полная история передаются файлом. Содержимое ссылки сжато, но не зашифровано.

## Границы MVP

Только PostgreSQL. Нет аккаунтов и серверной синхронизации. Платформа рассчитана на небольшие учебные базы; тяжёлый SQL может исчерпать память вкладки. Полный DDL доступен кодом; визуальный конструктор создаёт новые таблицы, а редактирование существующих объектов выполняется через DDL. Views, triggers и functions не редактируются через ERD.
